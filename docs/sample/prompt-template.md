# Sample Prompt Template

예시 문서입니다. Concept & Flow Template 스토리가 raw import 로 불러와 TemplateStack 렌더를 보여줍니다.
실제 프로젝트에서는 이 파일 대신 `docs/{project}/image-generation/prompt-template.md`를 둡니다.

## Sample Template

```
A minimalist {subject} product shot.
Background: #FFFFFF wall tint.
Accent: #0000FF, single non-negotiable accent color.
Composition: {format}, centered.
Shape: borderRadius 0, sharp corners only.
Style: photorealistic, symmetrical.
No environment, no text, no diagonal framing.
```
