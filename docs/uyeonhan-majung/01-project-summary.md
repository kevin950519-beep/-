## 1. 한 줄 요약

> 관람객이 전시 제목과 작가의 문장을 먼저 만나고, 나무 가지의 선을 따라 작품을 만난 뒤, 전시장 방문까지 이어가게 하는 개인전 「우연한 마중」의 온라인 랜딩페이지.

태그라인: 작가의 문장을 지나, 가지 끝에서 만나는 이야기.

---

## 2. 배경과 목적

- 문제 또는 기회: 작품 사진과 일정 안내만으로는 작가가 전하려는 따뜻함, 낯섦, 끝없이 이어지는 이야기의 감각이 전달되지 않는다.
- 왜 지금, 왜 우리: 개인전 개최에 맞춰 작가 노트와 작품 사진이 준비돼 있다. 문장이 감상의 문을 열고 작품이 이야기를 이어받는 구조를 만들 수 있다.
- 왜 만드는가: 전시의 정서 전달, 감상의 출발점 마련, 가지가 눈에 들어오는 작품 순서, 실제 전시로의 초대.
- 기대 효과: 작가 노트와 작품이 하나의 흐름으로 기억된다. 가지의 형태와 재료에 대한 호기심이 생긴다.
- 기대 효과: 방문 전에는 초대장, 전시 종료 후에는 작품과 이야기를 다시 만나는 기록이 된다.

제목의 해석: 「우연한 마중」은 예상하지 못한 만남과 누군가를 기다리는 마음이 함께 담긴 제목이다. 문장을 읽고 작품을 발견하는 순간 작품이 먼저 기다리고 있었던 듯한 감각을 경험하게 한다. (웹사이트의 감상 흐름 제안이며 작가 확인이 필요하다)

## 3. 정체성

### 3.1 핵심 가치 (최대 3)

| 이름 | 한 줄 | 반대말 (하지 않는 태도) |
|---|---|---|
| 이야기의 시작 | 문장이 먼저 마음에 닿는다 | 사진부터 쏟아내는 도입 |
| 낯선 만남 | 가지의 선을 따라 새로운 풍경을 발견한다 | 작품을 한 번에 다 보여주는 나열 |
| 열린 감상 | 이야기는 관람객의 안에서 계속된다 | 해석을 단정하는 해설 |

### 3.2 태도 키워드 (최대 5, 단어만)

따뜻함 · 시적 간결함 · 작품에 충실 · 감상의 자율 · 여백

### 3.3 포지셔닝 (선택)

| 축 | 우리의 선택 | 반대 축 |
|---|---|---|
| 커뮤니케이션 | 조용히 말을 건네는 초대장 | 행사 홍보 전단 |
| 감상 순서 | 문장에서 작품으로 | 작품 갤러리 먼저 |
| 화면의 역할 | 가지가 주인공, 화면은 비켜선다 | 장식이 주인공 |

### 3.4 정보의 역할

| 콘텐츠 | 역할 | 작성 기준 |
|---|---|---|
| 작가 노트 | 감상의 문을 여는 작가의 언어 | 원문 유지 |
| 구간별 문구 | 문장과 작품 사이를 연결 | 짧게, 작가 노트와 구분 |
| 작품 정보 | 작품에 대한 구체적 이해 | 공식 작품명·재료·크기·연도 |
| 관람 안내 | 실제 방문 지원 | 일정·장소·운영 시간을 명확히 |

## 6. 범위와 성공 기준

- 포함: 반응형 한 페이지, 전시 제목으로 시작하는 첫 화면, 작가 노트, 작품 사진, 좁은 간격으로 이어 붙은 작품 사진 그리드 스크롤, 작품 정보 확대와 이전·다음 넘겨보기, 작가의 글(전문), 작가 소개, 관람 안내(별도 구간), 구간 이동 메뉴(읽는 위치 표시), 전시 상태 표시(따라다니는 사이드 글자), 헤더의 길찾기·작가 인스타그램·링크 공유, 푸터
- 제외: 작품 판매와 결제
- 제외: 방명록, 댓글 등 관람객이 글을 남기는 기능
- 제외: 회원가입과 로그인
- 제외: 가지를 흔들거나 변형하는 효과
- 제외: 영상 (사진만 사용)
- 제약: 작품 사진은 5장이다. 미확정 정보는 비워 두고 진행한다.
- 제약: 이 페이지의 감상 순서는 실제 전시장 동선과 별개로 설계한다.

| 성공 기준 | 확인 방법 |
|---|---|
| 첫 화면에서 전시 제목이 먼저 기억되고, 글자가 모두 나타난 뒤 원이 2초 동안 그려지면 저절로(터치하면 바로) 작품 분위기가 열린다 | 5인 첫 화면 관찰 |
| PC와 모바일 모두 가지의 선과 방향이 보인다 | 기기별 화면 점검 |
| 히어로에서 작가 노트, 작품으로 자연스럽게 이어진다 | 5인 감상 흐름 인터뷰 |
| 확대 화면에서 작품 전체 형태를 확인한다 | 구간별 화면 점검 |
| 원하는 속도로 이동하고 작품을 고른다 | 메뉴 이동 과업 테스트 |
| 일정과 장소를 메뉴에서 바로 찾는다 | 5인 과업 테스트 |
| 관람 후 문장과 가지의 이미지가 함께 기억된다 | 방문 후 한 줄 질문 |
