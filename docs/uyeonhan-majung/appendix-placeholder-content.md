## 1. 사용 원칙

- 사용자가 "배치를 먼저 잡고, 정보는 나중에 알려주겠다"고 해서 비어 있던 값을 임시로 채운다.
- 이 문서의 값은 모두 `(임시)`다. 실제처럼 보이지 않도록 날짜와 숫자는 `0`으로 채운다.
- 코드의 데이터 파일에는 `isPlaceholder: true` 필드를 두어 교체 대상을 한눈에 찾는다.
- 작가 노트, 작가 약력, 전시 정보(관람료 제외)는 받은 실제 값이다. 작품명, 재료, 크기, 연도, 관람료는 임시 값이라 알려 주는 대로 교체한다.
- 임시 값은 공개 전에 반드시 교체한다. 공개 전 점검 항목은 4절 끝에 둔다.

## 3. 작품

사진 순서는 페이지 위에서 아래 순서다. 히어로는 전시 포스터를 쓰고, 작품 구간에는 아래 5장이 전시 작품 타이틀 아래 그리드로 나온다. 여인 앞 사진은 중복이라 쓰지 않는다. 작품명은 모두 같은 임시 값이다.

| # | 사진 파일 | 작품명 | 구간 |
|---|---|---|---|
| 1 | `사과들.png` | 우연한 마중 | 작품 1번째 |
| 2 | `여인_뒤.png` | 우연한 마중 | 작품 2번째 |
| 3 | `거울사과.png` | 우연한 마중 | 작품 3번째 |
| 4 | `빛나는 화분.png` | 우연한 마중 | 작품 4번째 |
| 5 | `사과셋나무하나.png` | 우연한 마중 | 작품 5번째 |

작품 정보는 모든 작품을 같은 값으로 통일한다(작가 확인 전 임시). 화면에는 제목 옆에 이어서 한 줄로 나온다.

| 항목 | 값 |
|---|---|
| 작품명 | 우연한 마중 |
| 연도 | 2026 |
| 재료 | wood, plaster |
| 크기 | 70x70x140(cm) |
| 화면 표기 | 우연한 마중 (큰 글자) 2026 wood, plaster 70x70x140(cm) (작은 글자) |

예외 0: `사과들.png`(1번째) 작품은 크기가 30x30x90(cm)이고 나머지는 같다. 화면 표기는 "우연한 마중 2026 wood, plaster 30x30x90(cm)"이다.

예외 1: `거울사과.png`(3번째)와 `빛나는 화분.png`(4번째) 작품은 재료 wood, plaster, acrylic, 크기 60x60x80(cm)이고 나머지는 같다. 화면 표기는 "우연한 마중 2026 wood, plaster, acrylic 60x60x80(cm)"이다.

예외 2: `사과셋나무하나.png`(5번째) 작품은 재료 resin, wood, 크기 30x30x90(cm)이며 나머지(작품명, 연도, 표기 형식)는 같다. 화면 표기는 "우연한 마중 2026 resin, wood 30x30x90(cm)"이다.

## 4. 작가노트와 구간 문구

### 4.1 작가노트 (실제 원문)

```
부드러운 이야기를 품고
우연인 듯 마중 나오는 따뜻하고 낯선 바람,
깊이를 알 수 없는 무한한 이야기
```

### 4.2 구간별 문구 (임시)

| 구간 | 임시 문구 |
|---|---|
| 이야기의 문 | 우연한 마중 (제목), 임미라 개인전 (부제), 잠시 후 전시로 들어갑니다 (진행 표시 아래 안내) |
| 작품 (전시 작품 타이틀) | 전시 작품 |
| 작가 소개 | 작가 프로필 |

### 4.3 공개 전 점검

| 점검 | 방법 |
|---|---|
| 임시 값이 남지 않았다 | 데이터 파일에서 `isPlaceholder` 검색 |
| 날짜와 숫자에 `0`이 남지 않았다 | 화면에서 `0000` 검색 |
| 작품명이 공식 작품명이다 | 작가 확인 |
